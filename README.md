# Apex Auto Detailing

Create a premium, modern, fully responsive website for a fictional car detailing studio called APEX DETAILING.
DESIGN:
Dark luxury aesthetic.
Almost black and graphite backgrounds.
White typography with bright orange accents.
Premium automotive photography.
Minimalist layout with smooth animations.
Modern typography and generous spacing.
The website should look like a real professional business, not a generic template.
WEBSITE STRUCTURE:
Header:
APEX DETAILING logo.
Navigation: Services, About, Gallery, Contacts.
Bright orange "Book Now" button.
Hero section:
Large cinematic photo of a luxury sports car.
Main heading: "PERFECTION IN EVERY DETAIL."
Subtitle about professional car detailing.
Orange "Explore Services" button.
Services:
Paint correction.
Ceramic coating.
Interior detailing.
Full car detailing. Each service should have a short description and attractive image.
About:
Short introduction to the studio.
Emphasize quality, precision and attention to detail.
Gallery:
Attractive grid of premium cars and detailing work.
Contact section:
Phone number placeholder.
Address placeholder.
Working hours.
Contact form with name, phone and message fields.
Footer:
APEX DETAILING branding and navigation.
IMPORTANT:
All website text must be in Russian.
Make the design visually impressive and polished.
Ensure the layout works on desktop and mobile.
Use realistic placeholder content.
Make buttons and navigation functional where possible.
